# Docker Services Lab

A collection of self-hosted services deployed with Docker Compose on Ubuntu Server.

---

## Services

| Service | Purpose |
|----------|---------|
| Portainer | Container management |
| Homepage | Dashboard |
| Uptime Kuma | Monitoring |
| File Browser | File management |
| Nginx Proxy Manager | Reverse proxy |
